# ai-study-buddy
An AI-powered Study Buddy built with Streamlit and Gemini for high school students. Features textbook OCR image analysis, English/Urdu text simplification, voice question handling, and automatic quiz generation to boost classroom accessibility.
# 🎓 AI Study Buddy for Your Syllabus

An interactive educational platform designed to enhance learning and classroom accessibility.

### 🚀 Core Features
* 📸 **Snap & Simplify (OCR):** Upload textbook images to analyze and extract text automatically.
* 🗣️ **Voice Questions:** Ask questions naturally using speech-to-text integration.
* 🔊 **Read Aloud:** Built-in Text-to-Speech functionality to hear content spoken.
* 📝 **Quiz & Flashcards:** Instantly turn your study materials into interactive quizzes.

### 🛠️ Built With
* **Streamlit** (Interactive Web Interface)
* **Google Gemini 2.5 Flash** (Advanced AI Model)
* **gTTS** (Google Text-to-Speech Engine)
* **Pillow** (Image Processing Framework)
